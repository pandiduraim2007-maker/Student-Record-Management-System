
# Student Record Management System

A Student Record Management System developed using C Programming and Singly Linked List.

## Project Description
This project is designed to manage student details efficiently using a Singly Linked List data structure.

## Features
- Add Student Details
- Display Student Records
- Search Student Records
- Update Student Marks
- Delete Student Records

## Student Details
- Register Number
- Student Name
- Department
- Year
- Mark

## Technologies Used
- C Programming
- Singly Linked List

## Data Structures Concepts
- Structures
- Pointers
- Dynamic Memory Allocation
- Linked List Operations

## How to Run
1. Download the C source file.
2. Open it using a C compiler.
3. Compile and execute the program.
